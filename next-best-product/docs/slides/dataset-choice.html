03 · Vì sao chọn Expedia

Vì sao chọn Expedia làm dataset

Schema

Expedia Hotel Recommendations

Log search / click / book thật từ Expedia.

  • train.csv: date_time, user_id, srch_ci/co, srch_adults/children/rm_cnt, is_package, is_booking, cnt, hotel_continent/country/market, hotel_cluster (0-99)
  • destinations.csv: 149 latent feature/destination trích từ review text

Lý do chọn

Log thật, quy mô lớn (37.67M dòng, 1.2M user) — đủ để train nhiều họ mô hình trong cùng một sprint

Field có sẵn context (số người, ngày book, package) — không cần enrich thêm để test context-aware

Có sẵn ma trận user × hotel_cluster (qua is_booking) để làm CF ngay; đồng thời tách được click/book trong cùng luồng → dựng được session hành động của user

Dữ liệu có tính sparse / cold-start

Yelp Open Dataset (Đề tài 2) được phân tích riêng ở phần sau — dùng làm dataset dự phòng nếu domain Hotel/Travel bị trùng với nhóm khác.
